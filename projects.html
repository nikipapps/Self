What I've been learning

My web development coursework has introduced me to the building blocks of websites. I'm learning to organize information clearly with HTML and style it with CSS. These projects help me put individual techniques together into a complete page.

CSS Box Model

The box model explains how an element's content, padding, border, and margin fit together. Practicing width, padding, borders, and margins helps me control spacing and create layouts that are easier to read.

My Portfolio

This four-page portfolio practices semantic HTML, meaningful headings, accessible image descriptions, and navigation between related pages. A shared external stylesheet keeps the colors, typography, and navigation consistent.

Responsive Layout

Flexbox lets content sit in columns when there is enough room and stack on smaller screens. A media query helps the site remain comfortable to use on a phone or tablet.

Skills I'm practicing

  • HTML: page structure, links, images, lists, and semantic elements.
  • CSS: selectors, colors, typography, borders, spacing, and backgrounds.
  • Navigation: consistent menus with hover and keyboard-focus effects.
  • Responsive design: layouts that adapt to different screen widths.
  • Testing: checking links, reviewing code, and fixing mistakes.

An idea for a future project

I would like to create a small educational website about gecko care or a gaming-themed page. It could include organized topics, helpful images with alt text, and a design that works well on mobile devices. It would be a good way to practice while writing about something I enjoy.
